# Supply Chain Demand Forecasting & Decision Intelligence Pipeline

An end-to-end MLOps and time-series forecasting pipeline built to simulate enterprise supply chain inventory optimization. This project ingests nearly 1 million transactional records into a containerized relational database, automates data ingestion pipelines, and extracts advanced time-series features for predictive modeling.

---

## Business Context & Objective
In modern supply chain and manufacturing ecosystems, accurate demand forecasting is critical for reducing stockouts, optimizing inventory holding costs, and driving operational efficiency. This project establishes a foundational **Decision Intelligence** workflow by transforming raw point-of-sale data into structured, feature-engineered datasets ready for machine learning consumption.

---

## Tech Stack & Architecture
* **Database & Infrastructure:** PostgreSQL running inside an isolated Docker container (`local-postgres`), managed via `SQLAlchemy` and `psycopg2`.
* **Data Processing & Feature Engineering:** Python (`pandas`), leveraging vectorized operations for time-series transformations.
* **Environment & MLOps:** Python virtual environments (`.venv`), modular script architecture, and reproducible containerization.
